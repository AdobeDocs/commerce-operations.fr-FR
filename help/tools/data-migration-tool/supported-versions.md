# Versions prises en charge pour la migration des données

Le [!DNL Data Migration Tool] prend en charge la migration _à partir_ versions suivantes :

* ADOBE COMMERCE :
  * 1.11.x
  * 1.12.x
  * 1.13.x
  * 1.14.x
* MAGENTO OPEN SOURCE :
  * 1.6.x
  * 1.7.x
  * 1.8.x
  * 1.9.x

Si vous migrez de Magento Open Source vers Adobe Commerce, les versions suivantes sont prises en charge :

* 1.6.x
* 1.7.x
* 1.8.x
* 1.9.x

## Migration vers la version

Pour en savoir plus sur les versions prises en charge (celle vers laquelle vous migrez), consultez la page [Version](https://github.com/magento/data-migration-tool/releases) de l’[!DNL Data Migration Tool].
