# ACP2E-4875 : les utilisateurs administrateurs se sont déconnectés lors de l’ouverture de comptes clients avec des carnets d’adresses volumineux

Le correctif ACP2E-4875 corrige le problème en raison duquel l’affichage de comptes clients avec des carnets d’adresses volumineux dans l’administrateur déconnecte de manière inattendue les utilisateurs administrateurs. Ce correctif est disponible lorsque la version 1.1.82 de [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) est installée. L’ID du correctif est ACP2E-4875. Notez que ce problème doit être résolu dans Adobe Commerce 2.4.10.

## Produits et versions concernés

**Le correctif est créé pour la version Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.8-p3

**Compatible avec les versions d’Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.5 - 2.4.9

>[!NOTE]
>
>Le correctif peut s’appliquer à d’autres versions avec de nouvelles versions de [!DNL Quality Patches Tool]. Pour vérifier si le correctif est compatible avec votre version d’Adobe Commerce, mettez à jour le package `magento/quality-patches` vers la dernière version et vérifiez la compatibilité sur la page [[!DNL Quality Patches Tool] : Rechercher des correctifs](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Utilisez l’ID du correctif comme mot-clé de recherche pour localiser le correctif.

## Problème

Les utilisateurs administrateurs sont déconnectés de manière inattendue lors de l’affichage de comptes clients avec des carnets d’adresses volumineux dans l’administrateur.

<u>Conditions préalables</u> :

Un compte client possède un carnet d’adresses volumineux contenant environ 5 000 adresses enregistrées ou plus.

<u>Procédure à suivre </u> :

1. Connectez-vous à l’administrateur.
1. Accédez à **[!UICONTROL Customers]** > **[!UICONTROL All Customers]**.
1. Dans la colonne **[!UICONTROL Actions]** , cliquez sur **[!UICONTROL Edit]** pour un compte client disposant d’un carnet d’adresses volumineux.
1. Sur la page client, ouvrez l’onglet **[!UICONTROL Addresses]** .

<u>Résultats attendus</u> :

La page client se charge correctement et toutes les adresses enregistrées du client s’affichent.

<u>Résultats réels</u> :

1. La personne en charge de l’administration est déconnectée de manière inattendue.
1. La session dépasse la taille maximale autorisée et une entrée de journal similaire à *Taille de la session de 1421468 taille maximale de la session autorisée de 256000* est enregistrée.
