# ACP2E-4840 : la requête de produits GraphQL renvoie une quantité nulle pour les produits en stock sur les stocks d’inventaire personnalisés

Le correctif ACP2E-4840 corrige le problème en raison duquel le champ de quantité dans la requête GraphQL de produits renvoie la valeur null pour les produits en stock et disponibles à la vente sur les stocks d’inventaire personnalisés. Ce correctif est disponible lorsque la version 1.1.82 de [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) est installée. L’ID du correctif est ACP2E-4840. Notez que ce problème doit être résolu dans Adobe Commerce 2.4.10.

## Produits et versions concernés

**Le correctif est créé pour la version Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.8-p4

**Compatible avec les versions d’Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.8 - 2.4.8-p5

>[!NOTE]
>
>Le correctif peut s’appliquer à d’autres versions avec de nouvelles versions de [!DNL Quality Patches Tool]. Pour vérifier si le correctif est compatible avec votre version d’Adobe Commerce, mettez à jour le package `magento/quality-patches` vers la dernière version et vérifiez la compatibilité sur la page [[!DNL Quality Patches Tool] : Rechercher des correctifs](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=fr). Utilisez l’ID du correctif comme mot-clé de recherche pour localiser le correctif.

## Problème

Le champ de quantité dans la requête GraphQL de produits renvoie la valeur null pour les produits qui sont en stock et disponibles à la vente sur des stocks d’inventaire personnalisés.

<u>Conditions préalables</u> :

MSI est activé.

<u>Procédure à suivre </u> :

1. Créez une nouvelle source.
1. Dans la barre latérale d’administration, accédez à **[!UICONTROL Stores]** > **[!UICONTROL Inventory]** > **[!UICONTROL Stock]**.
1. Cliquez sur **[!UICONTROL Add New Stock]**.
1. Développez **[!UICONTROL Sales Channels]** et sélectionnez l’**[!UICONTROL Websites]** où le stock est disponible.
1. Développez **[!UICONTROL Sources]**, cliquez sur **[!UICONTROL Assign Sources]**, sélectionnez la source à affecter, puis cliquez sur **[!UICONTROL Done]**.
1. Dans la barre latérale d’administration, accédez à **[!UICONTROL Catalog]** > **[!UICONTROL Products]** et ouvrez un produit existant en mode d’édition.
1. Dans la section **[!UICONTROL Sources]** , attribuez la source personnalisée, définissez **[!UICONTROL Source Item Status]** sur **[!UICONTROL In Stock]**, saisissez une valeur différente de zéro pour **[!UICONTROL Qty]** et enregistrez le produit.
1. Vérifiez dans **[!UICONTROL Catalog]** > **[!UICONTROL Products]** que le produit affiche une **[!UICONTROL Salable Quantity]** différente de zéro pour le site Web affecté au stock personnalisé.
1. Exécutez la requête `products` [!DNL GraphQL] suivante pour ce SKU par rapport à la vue de magasin affectée au site web qui utilise le stock personnalisé :

   ```
   query {
     products(filter: { sku: { in: ["product_dynamic_1"] } }) {
       items {
         sku
         name
         stock_status
         quantity
         max_sale_qty
       }
     }
   }
   ```

1. Observez la réponse :

   ```
   {
     "data": {
       "products": {
         "items": [
           {
             "sku": "product_dynamic_1",
             "name": "Simple Product 1",
             "stock_status": "IN_STOCK",
             "quantity": null,
             "max_sale_qty": 10000
           }
         ]
       }
     }
   }
   ```

<u>Résultats attendus</u> :

La réponse de GraphQL renvoie une valeur de quantité non nulle pour les produits qui sont en stock et vendables sur le magasin/site web actuel.

<u>Résultats réels</u> :

La réponse GraphQL renvoie `quantity = null` alors que `stock_status` = `IN_STOCK` pour les produits qui sont en stock et vendables dans l’administration lorsque le magasin utilise un stock MSI personnalisé.
