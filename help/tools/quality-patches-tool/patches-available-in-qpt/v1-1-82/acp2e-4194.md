# ACP2E-4194 : les requêtes GraphQL avec des noms de filtres inconnus entraînent des logs d’exceptions PHP

Le correctif ACP2E-4194 corrige le problème où les requêtes GraphQL avec des noms de filtres inconnus provoquent des logs d’exceptions PHP. Ce correctif est disponible lorsque la version 1.1.82 de [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) est installée. L’ID du correctif est ACP2E-4194. Notez que ce problème doit être résolu dans Adobe Commerce 2.4.9.

## Produits et versions concernés

**Le correctif est créé pour la version Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.7-p10, 2.4.8-p5

**Compatible avec les versions d’Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.7-p10, 2.4.8-p5

>[!NOTE]
>
>Le correctif peut s’appliquer à d’autres versions avec de nouvelles versions de [!DNL Quality Patches Tool]. Pour vérifier si le correctif est compatible avec votre version d’Adobe Commerce, mettez à jour le package `magento/quality-patches` vers la dernière version et vérifiez la compatibilité sur la page [[!DNL Quality Patches Tool] : Rechercher des correctifs](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Utilisez l’ID du correctif comme mot-clé de recherche pour localiser le correctif.

## Problème

Problème où les requêtes GraphQL avec des noms de filtres inconnus provoquent des logs d&#39;exceptions PHP.

<u>Procédure à suivre </u> :

Envoyez une requête GraphQL dont le nom de filtre est inconnu ou incorrect :

```
query Test($filter: FindFilterType){ cmsBlocks(identifiers:["home"]) { items { title } } }
```

<u>Résultats attendus</u> :

Un code de réponse 4XX est renvoyé si la requête ne peut pas être analysée, si la requête n’est pas autorisée ou s’il existe un autre problème général avec la requête. Si la requête peut être analysée et traitée, un code de réponse *200* est renvoyé.

<u>Résultats réels</u> :

Une erreur de serveur interne est renvoyée dans la réponse, avec l’erreur suivante dans `exception.log` :

```
report.CRITICAL: LogicException: Config element "FindFilterType" is not declared in GraphQL schema in /var/lib/internal/Magento/Framework/GraphQl/Config.php:57
```
