# ACP2E-4547 : l’administrateur ne peut pas ajouter un produit de catalogue par défaut à une commande s’il n’est pas affecté au catalogue partagé de l’entreprise

Le correctif ACP2E-4547 corrige le problème où un administrateur ne peut pas ajouter un produit à une commande via l’interface d’administration si le produit n’est pas affecté au catalogue partagé de l’entreprise. Ce correctif est disponible lorsque la version 1.1.82 de [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) est installée. L’ID du correctif est ACP2E-4547. Notez que ce problème doit être résolu dans la version 1.5.3 d’Adobe Commerce B2B.

## Produits et versions concernés

**Le correctif est créé pour la version Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) B2B 1.5.2-p3

**Compatible avec les versions d’Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) B2B >=1.5.0 &lt;1.5.3

>[!NOTE]
>
>Le correctif peut s’appliquer à d’autres versions avec de nouvelles versions de [!DNL Quality Patches Tool]. Pour vérifier si le correctif est compatible avec votre version d’Adobe Commerce, mettez à jour le package `magento/quality-patches` vers la dernière version et vérifiez la compatibilité sur la page [[!DNL Quality Patches Tool] : Rechercher des correctifs](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Utilisez l’ID du correctif comme mot-clé de recherche pour localiser le correctif.

## Problème

Les utilisateurs administrateurs ne peuvent pas ajouter de produits à une commande dans l’administrateur si ces produits ne sont pas affectés au catalogue partagé de la société.

<u>Conditions préalables</u> :

* B2B est installé.
* Les fonctionnalités de catalogue et d’entreprise partagées sont activées.

<u>Procédure à suivre </u> :

1. Créez un groupe de clients.
1. Créez une nouvelle société et affectez-la au groupe de clients nouvellement créé.
1. Dans la barre latérale d’administration, accédez à **[!UICONTROL Customers]** > **[!UICONTROL All Customers]**, ouvrez l’administrateur d’entreprise nouvellement créé et vérifiez que la valeur du **[!UICONTROL Customer Group]** correspond au groupe de clients de l’entreprise.
1. Dans la barre latérale d’administration, accédez à **[!UICONTROL Customers]** > **[!UICONTROL All Customers]** et recherchez le client dans la grille.
1. Dans la colonne **[!UICONTROL Action]**, cliquez sur **[!UICONTROL Edit]**. Dans l’en-tête de l’espace de travail, cliquez sur **[!UICONTROL Create Order]**.
1. Sur la page du sélecteur de magasins, utilisez le sélecteur d’affichage du magasin dans le coin supérieur gauche pour développer le site web ou la hiérarchie de magasin cible, puis sélectionnez l’affichage du magasin.
1. Sur la page **[!UICONTROL Create New Order]**, cliquez sur **[!UICONTROL Add Products By SKU]**.
1. Saisissez le SKU d’un produit qui existe dans le catalogue par défaut mais qui n’est pas affecté au catalogue partagé de l’entreprise, puis essayez d’ajouter le produit à la commande.

<u>Résultats attendus</u> :

Les utilisateurs administrateurs peuvent ajouter des produits du catalogue par défaut aux commandes des sociétés affectées uniquement à des groupes de clients standard, comme ils le peuvent sur le storefront.

<u>Résultats réels</u> :

Le système affiche le message d’erreur suivant : *Le SKU que vous avez saisi n’est pas disponible dans le catalogue partagé. Vérifiez le SKU et réessayez.*
