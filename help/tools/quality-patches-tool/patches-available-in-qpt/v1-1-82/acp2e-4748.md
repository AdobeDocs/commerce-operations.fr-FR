# ACP2E-4748 : l’expiration des points de récompense s’exécute lentement sur les magasins avec un historique de points de récompense important

Le correctif ACP2E-4748 corrige le problème où l’expiration des points de récompense s’exécute lentement sur les magasins ayant un historique de points de récompense important, ce qui entraîne des retards dans l’expiration des points de récompense. Ce correctif est disponible lorsque la version 1.1.82 de [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) est installée. L’ID du correctif est ACP2E-4748. Notez que ce problème doit être résolu dans Adobe Commerce 2.4.9.

## Produits et versions concernés

**Le correctif est créé pour la version Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.8-p1

**Compatible avec les versions d’Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.7 - 2.4.8-p5

>[!NOTE]
>
>Le correctif peut s’appliquer à d’autres versions avec de nouvelles versions de [!DNL Quality Patches Tool]. Pour vérifier si le correctif est compatible avec votre version d’Adobe Commerce, mettez à jour le package `magento/quality-patches` vers la dernière version et vérifiez la compatibilité sur la page [[!DNL Quality Patches Tool] : Rechercher des correctifs](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Utilisez l’ID du correctif comme mot-clé de recherche pour localiser le correctif.

## Problème

L’expiration des points de récompense s’exécute lentement sur les magasins avec un historique de points de récompense volumineux, ce qui entraîne des retards dans l’expiration des points de récompense.

<u>Conditions préalables</u> :

Le magasin a un jeu de données de points de récompense important.

<u>Procédure à suivre </u> :

1. Accédez à **Admin** > **[!UICONTROL Stores]** > **Paramètres** > **Configuration** > **[!UICONTROL Customers]** > **[!UICONTROL Reward Points]**.
1. Définissez **[!UICONTROL Enable Reward Points Functionality]** sur *Oui*, définissez **[!UICONTROL Reward Points Expire in (days)]** sur une valeur positive, puis cliquez sur **[!UICONTROL Save Config]**.
1. Vérifiez que les tables `magento_reward` et `magento_reward_history` contiennent un très grand nombre d&#39;enregistrements.
1. Attendez que le traitement cron `magento_reward_expire_points` s’exécute.
1. Mesurez le temps d’exécution de la requête exécutée par `Magento\Reward\Model\ResourceModel\Reward\History::expirePoints()`.

<u>Résultats attendus</u> :

L’expiration des points de récompense planifiés se termine dans un délai raisonnable sans retarder les autres traitements cron.

<u>Résultats réels</u> :

La tâche cron `magento_reward_expire_points` s’exécute lentement lorsque `magento_reward_history` contient un très grand volume de données.
