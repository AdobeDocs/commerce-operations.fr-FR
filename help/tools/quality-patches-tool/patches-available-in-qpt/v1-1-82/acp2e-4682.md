# ACP2E-4682 : pages de storefront qui vérifient les devis `isActive` créent des enregistrements de devis vides

Le correctif ACP2E-4682 corrige le problème en raison duquel la visite d’une page de storefront qui vérifie le statut de la `isActive` de devis crée des enregistrements de devis vides chaque fois que la page est chargée. Ce correctif est disponible lorsque la version 1.1.82 de [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) est installée. L’ID du correctif est ACP2E-4682. Notez que ce problème doit être résolu dans Adobe Commerce 2.4.10.

## Produits et versions concernés

**Le correctif est créé pour la version Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.7-p8

**Compatible avec les versions d’Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.5 - 2.4.9

>[!NOTE]
>
>Le correctif peut s’appliquer à d’autres versions avec de nouvelles versions de [!DNL Quality Patches Tool]. Pour vérifier si le correctif est compatible avec votre version d’Adobe Commerce, mettez à jour le package `magento/quality-patches` vers la dernière version et vérifiez la compatibilité sur la page [[!DNL Quality Patches Tool] : Rechercher des correctifs](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Utilisez l’ID du correctif comme mot-clé de recherche pour localiser le correctif.

## Problème

La visite d’une page de storefront qui vérifie le statut du `isActive` de devis crée un enregistrement de devis vide chaque fois que la page est chargée.

<u>Procédure à suivre :</u>

1. Personnalisez une page produit de storefront et ajoutez un bloc qui vérifie le statut de `isActive` du devis.
1. Connectez-vous à un compte client.
1. Rechargez la page produit sur le storefront.
1. Exécutez la requête suivante :

   ```
   SELECT COUNT(*) FROM quote;
   ```

1. Notez que le nombre de devis augmente chaque fois que la page produit est chargée.

<u>Résultats attendus :</u>

1. Un enregistrement de guillemet vide n’est pas créé lors du chargement de la page.

<u>Résultats réels:</u>

1. Un enregistrement de devis vide est créé chaque fois qu&#39;une page contenant le devis `isActive` la vérification est consultée.
