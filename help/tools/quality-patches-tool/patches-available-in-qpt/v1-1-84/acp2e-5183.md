# ACP2E-5183 : Le déploiement de contenu statique échoue sur PHP 8.5 avec `@magento_import`

Le correctif ACP2E-5183 corrige le problème où le déploiement du contenu statique échoue sur PHP 8.5 avec l&#39;erreur *Utiliser null comme décalage de tableau est obsolète* quand un module `LESS` fichier utilise la directive `@magento_import`. Ce correctif est disponible lorsque la version 1.1.84 de [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) est installée. L’ID du correctif est ACP2E-5183. Notez que ce problème doit être résolu dans Adobe Commerce 2.4.10.

## Produits et versions concernés

**Le correctif est créé pour la version Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.9

**Compatible avec les versions d’Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.4 - 2.4.9

>[!NOTE]
>
>Le correctif peut s’appliquer à d’autres versions avec de nouvelles versions de [!DNL Quality Patches Tool]. Pour vérifier si le correctif est compatible avec votre version d’Adobe Commerce, mettez à jour le package `magento/quality-patches` vers la dernière version et vérifiez la compatibilité sur la page [[!DNL Quality Patches Tool] : Rechercher des correctifs](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Utilisez l’ID du correctif comme mot-clé de recherche pour localiser le correctif.

## Problème

Le déploiement du contenu statique échoue en PHP 8.5 avec l&#39;erreur *Utiliser null comme décalage de tableau est obsolète* quand un module `LESS` fichier utilise la directive `@magento_import`.

<u>Conditions préalables</u> :

PHP 8.5 est installé.

<u>Procédure à suivre </u> :

1. Activez un module personnalisé qui fournit un fichier `email-inline.less` contenant un style de corps d’e-mail personnalisé et une directive de `@magento_import`.
1. Supprimez le contenu statique et les fichiers générés :

   ```
   rm -rf pub/static/frontend/* var/view_preprocessed/* generated/code/*
   ```

1. Exécutez le déploiement de contenu statique à l’aide de la stratégie compacte :

   ```
   bin/magento setup:static-content:deploy --ansi --no-interaction -f -s compact --jobs 4 --no-html-minify
   ```

<u>Résultats attendus</u> :

Le déploiement de contenu statique s’est terminé avec succès et génère le fichier CSS compilé pour le fichier `LESS` fourni par le module.

<u>Résultats réels</u> :

Le déploiement de contenu statique est interrompu lors de la compilation du fichier `email-inline.less` et des rapports fournis par le module :

```
Deprecated Functionality: Using null as an array offset is deprecated, use an empty string instead in <magento_root>/vendor/magento/framework/Component/ComponentRegistrar.php on line 71
```
