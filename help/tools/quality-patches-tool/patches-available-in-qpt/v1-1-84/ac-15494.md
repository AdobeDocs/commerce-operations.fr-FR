# AC-15494 : la requête de produits GraphQL renvoie des noms de produits avec échappement HTML

Le correctif AC-15494 corrige le problème où la requête `products` renvoie les noms de produit avec des caractères spéciaux dans une séquence d’échappement HTML au lieu de leurs caractères d’origine. Ce correctif est disponible lorsque la version 1.1.84 de [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) est installée. L’ID du correctif est AC-15494. Notez que ce problème doit être résolu dans Adobe Commerce 2.4.9.

## Produits et versions concernés

**Le correctif est créé pour la version Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.8-p5

**Compatible avec les versions d’Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.8 - 2.4.8-p5

>[!NOTE]
>
>Le correctif peut s’appliquer à d’autres versions avec de nouvelles versions de [!DNL Quality Patches Tool]. Pour vérifier si le correctif est compatible avec votre version d’Adobe Commerce, mettez à jour le package `magento/quality-patches` vers la dernière version et vérifiez la compatibilité sur la page [[!DNL Quality Patches Tool] : Rechercher des correctifs](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=fr). Utilisez l’ID du correctif comme mot-clé de recherche pour localiser le correctif.

## Problème

La requête `products` renvoie les noms de produits avec des caractères spéciaux dans une séquence d’échappement HTML au lieu de leurs caractères d’origine.

<u>Procédure à suivre </u> :

1. Créez un produit nommé `55" 4K UHD Smart TV` avec les `testsku` de SKU.
1. Envoyez la requête GraphQL suivante :

   ```
   query {
       products(search: "testsku" ) {
           items {
               sku
               name
               description {
                   html
               }
               short_description {
                   html
               }
   
               price_range {
                   maximum_price {
                       final_price {
                           value
                           currency
                       }
                       regular_price {
                           value
                           currency
                       }
                   }
               }
           }
       }
   }
   ```

<u>Résultats attendus</u> :

La requête `products` renvoie le nom du produit enregistré avec ses guillemets doubles d’origine.

<u>Résultats réels</u> :

Le nom de produit renvoyé contient des guillemets doubles d’échappement HTML au lieu des caractères d’origine.
