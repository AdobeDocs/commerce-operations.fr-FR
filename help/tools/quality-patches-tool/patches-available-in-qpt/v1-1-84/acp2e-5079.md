# ACP2E-5079 : les segments clients correspondent uniquement au premier site web avec partage de compte mondial

Le correctif ACP2E-5079 corrige le problème où un segment client affecté à plusieurs sites web renvoie les clients correspondants uniquement à partir du premier site web lorsque les comptes clients sont partagés globalement. Ce correctif est disponible lorsque la version 1.1.84 de [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) est installée. L’ID du correctif est ACP2E-5079. Notez que ce problème doit être résolu dans Adobe Commerce 2.4.10.

## Produits et versions concernés

**Le correctif est créé pour la version Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.7-p10

**Compatible avec les versions d’Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.4 - 2.4.9

>[!NOTE]
>
>Le correctif peut s’appliquer à d’autres versions avec de nouvelles versions de [!DNL Quality Patches Tool]. Pour vérifier si le correctif est compatible avec votre version d’Adobe Commerce, mettez à jour le package `magento/quality-patches` vers la dernière version et vérifiez la compatibilité sur la page [[!DNL Quality Patches Tool] : Rechercher des correctifs](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Utilisez l’ID du correctif comme mot-clé de recherche pour localiser le correctif.

## Problème

Un segment client affecté à plusieurs sites web renvoie les clients correspondants uniquement à partir du premier site web lorsque les comptes clients sont partagés globalement.

<u>Procédure à suivre </u> :

1. Dans la barre latérale d’administration, accédez à **[!UICONTROL Stores]** > **[!UICONTROL Settings]** > **[!UICONTROL Configuration]** > **[!UICONTROL Customers]** > **[!UICONTROL Customer Configuration]** > **[!UICONTROL Account Sharing Options]**, puis définissez **[!UICONTROL Share Customer Accounts]** sur **[!UICONTROL Global]**.
1. Créez deux sites web, puis créez des comptes clients enregistrés sur chaque site web et passez des commandes pour ces clients.
1. Accédez à **[!UICONTROL Customers]** > **[!UICONTROL Segments]** > **[!UICONTROL Add Segment]**, créez un segment actif pour les clients enregistrés, affectez-le aux deux sites web et ajoutez une condition d’historique de commandes qui correspond aux clients de test.
1. Enregistrez le segment, cliquez sur **[!UICONTROL Refresh Segment Data]**, puis passez en revue la grille de **[!UICONTROL Matched Customers]**.

<u>Résultats attendus</u> :

La grille de **[!UICONTROL Matched Customers]** répertorie tous les clients enregistrés qui répondent à la condition de segment sur les deux sites web attribués.

<u>Résultats réels</u> :

La grille **[!UICONTROL Matched Customers]** répertorie uniquement les clients correspondant au premier site web attribué.
