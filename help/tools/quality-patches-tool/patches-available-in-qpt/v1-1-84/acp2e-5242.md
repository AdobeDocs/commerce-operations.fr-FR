# ACP2E-5242 : GraphQL utilise l’ID de magasin comme ID de site web lors des demandes d’ajout au panier

Le correctif ACP2E-5242 corrige le problème en raison duquel la vérification de la disponibilité du produit lors de l’ajout d’articles au panier affiche une erreur indiquant que le site web est introuvable. Ce correctif est disponible lorsque la version 1.1.84 de [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) est installée. L’ID du correctif est ACP2E-5242. Notez que ce problème doit être résolu dans Adobe Commerce 2.4.10.

## Produits et versions concernés

**Le correctif est créé pour la version Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.9

**Compatible avec les versions d’Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.9

>[!NOTE]
>
>Le correctif peut s’appliquer à d’autres versions avec de nouvelles versions de [!DNL Quality Patches Tool]. Pour vérifier si le correctif est compatible avec votre version d’Adobe Commerce, mettez à jour le package `magento/quality-patches` vers la dernière version et vérifiez la compatibilité sur la page [[!DNL Quality Patches Tool] : Rechercher des correctifs](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Utilisez l’ID du correctif comme mot-clé de recherche pour localiser le correctif.

## Problème

La vérification de la disponibilité du produit lors de l’ajout d’articles au panier affiche une erreur indiquant que le site web est introuvable.

<u>Procédure à suivre </u> :

1. Connectez-vous au panneau d’administration.
1. Accédez à **Admin** > **[!UICONTROL Stores]** > **Paramètres** > **[!UICONTROL All Stores]**, puis cliquez sur **[!UICONTROL Create Store View]**.
1. Créez une deuxième vue de magasin nommée « store_2 », par exemple.
1. Créez un panier d’invités vide avec une requête GraphQL à l’aide de l’en-tête HTTP « Store: store2 ».
1. Enregistrez l’ID de panier renvoyé.
1. Ajoutez un produit simple au panier avec une requête GraphQL à l’aide de l’en-tête HTTP « Store: store2 », du SKU du produit et de l’ID de panier.

<u>Résultats attendus</u> :

Le produit est correctement ajouté au panier via la requête GraphQL.

<u>Résultats réels</u> :

La requête GraphQL échoue et affiche le message « Le site web avec l’ID ... demandé est introuvable. Vérifiez le site web et réessayez. » à var/log/exception.log.
