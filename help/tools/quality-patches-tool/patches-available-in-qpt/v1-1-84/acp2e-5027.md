# ACP2E-5027 : les indexeurs ne se terminent pas lorsque le verrouillage de l’application utilise le fournisseur de verrouillage de fichiers

Le correctif ACP2E-5027 corrige le problème où les indexeurs ne se terminent jamais, car ils continuent à essayer d’acquérir leur propre verrou lorsque `use_application_lock` est activé et que le fournisseur de verrou de fichier est configuré. Ce correctif est disponible lorsque la version 1.1.84 de [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) est installée. L’ID du correctif est ACP2E-5027. Ce problème devrait être résolu dans Adobe Commerce 2.4.10.

## Produits et versions concernés

**Le correctif est créé pour la version Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.9

**Compatible avec les versions d’Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.4 - 2.4.9

>[!NOTE]
>
>Le correctif peut s’appliquer à d’autres versions avec de nouvelles versions de [!DNL Quality Patches Tool]. Pour vérifier si le correctif est compatible avec votre version d’Adobe Commerce, mettez à jour le package `magento/quality-patches` vers la dernière version et vérifiez la compatibilité sur la page [[!DNL Quality Patches Tool] : Rechercher des correctifs](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Utilisez l’ID du correctif comme mot-clé de recherche pour localiser le correctif.

## Problème

Les indexeurs ne se terminent jamais parce qu’ils continuent à essayer d’acquérir leur propre verrou lorsque `use_application_lock` est activé et que le fournisseur de verrou de fichier est configuré.

<u>Procédure à suivre </u> :

1. Dans `app/etc/env.php`, activez le verrouillage d’application pour les indexeurs et définissez le fournisseur de verrouillage sur fichier :

   ```
   'indexer' =>
   array (
     'use_application_lock' => true,
   ),
   'lock' =>
   array (
     'provider' => 'file',
     'config' =>
     array (
       'path' => '<magento_root>/var/lock',
     ),
   )
   ```

1. Exécutez l’indexeur de `catalog_product_category` :

   ```
   bin/magento indexer:reindex catalog_product_category
   ```

<u>Résultats attendus</u> :

La réindexation `catalog_product_category` s’est terminée correctement.

<u>Résultats réels</u> :

La réindexation ne se termine jamais.
