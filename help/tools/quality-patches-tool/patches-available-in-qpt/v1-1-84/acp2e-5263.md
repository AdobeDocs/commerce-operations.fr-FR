# ACP2E-5263 : l’exportation du produit CSV s’arrête tôt et omet les produits

Le correctif ACP2E-5263 corrige un problème en raison duquel l’exportation d’un produit CSV peut s’arrêter avant d’inclure tous les produits, ce qui génère un fichier incomplet. Ce correctif est disponible lorsque la version 1.1.84 de [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) est installée. L’ID du correctif est ACP2E-5263. Notez que ce problème doit être résolu dans Adobe Commerce 2.4.10.

## Produits et versions concernés

**Le correctif est créé pour la version Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.8-p5

**Compatible avec les versions d’Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.5 - 2.4.8-p5

>[!NOTE]
>
>Le correctif peut s’appliquer à d’autres versions avec de nouvelles versions de [!DNL Quality Patches Tool]. Pour vérifier si le correctif est compatible avec votre version d’Adobe Commerce, mettez à jour le package `magento/quality-patches` vers la dernière version et vérifiez la compatibilité sur la page [[!DNL Quality Patches Tool] : Rechercher des correctifs](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Utilisez l’ID du correctif comme mot-clé de recherche pour localiser le correctif.

## Problème

Les exportations de produits au format CSV peuvent s’arrêter avant que tous les produits ne soient inclus, ce qui génère un fichier incomplet.

<u>Procédure à suivre </u> :

1. Assurez-vous que le catalogue contient plusieurs produits et une vue de magasin secondaire.
2. Utilisez des produits de test pour lesquels un libellé d’image est défini pour la vue de magasin secondaire, mais aucune image de produit correspondante n’est disponible dans la vue de magasin par défaut.
3. Dans Admin, accédez à **[!UICONTROL System]** > **[!UICONTROL Data Transfer]** > **[!UICONTROL Export]**.
4. Définissez **[!UICONTROL Entity Type]** sur **[!UICONTROL Products]** et laissez **[!UICONTROL Export File Format]** défini sur **[!UICONTROL CSV]**.
5. Ne renseignez pas les filtres d’exportation et n’excluez pas les attributs.
6. Faites défiler vers le bas et cliquez sur **[!UICONTROL Continue]**.
7. Patientez jusqu’à la fin de l’exportation asynchrone, puis téléchargez et ouvrez le fichier CSV.

<u>Résultats attendus</u> :

L’exportation se termine et génère un fichier CSV contenant chaque produit.

<u>Résultats réels</u> :

L’exportation est interrompue au cours du processus, mais l’administrateur indique que le fichier d’exportation est prêt et fournit un fichier CSV auquel il manque certains produits.
