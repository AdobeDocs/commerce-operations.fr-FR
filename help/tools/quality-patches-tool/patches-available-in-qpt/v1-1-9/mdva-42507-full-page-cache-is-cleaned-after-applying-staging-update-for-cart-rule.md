# MDVA-42507 : le cache de pleine page est nettoyé après l’application de la mise à jour d’évaluation pour la règle de panier

Le correctif MDVA-42507 résout le problème de nettoyage du cache de page complète après l’application de la mise à jour d’évaluation pour la règle de panier. Ce correctif est disponible lorsque l’[outil de correctifs de qualité (QPT)](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.9 est installé. L’ID du correctif est MDVA-42507. Notez que le problème est planifié pour être corrigé dans Adobe Commerce 2.4.5.

## Produits et versions concernés

**Le correctif est créé pour la version Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.3-p1

**Compatible avec les versions d’Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.3 - 2.4.3-p1

>[!NOTE]
>
>Le correctif peut s’appliquer à d’autres versions avec de nouvelles versions de l’outil de correctifs de qualité. Pour vérifier si le correctif est compatible avec votre version d’Adobe Commerce, mettez à jour le package `magento/quality-patches` vers la dernière version et vérifiez la compatibilité sur la page [[!DNL Quality Patches Tool] : Rechercher des correctifs](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md). Utilisez l’ID du correctif comme mot-clé de recherche pour localiser le correctif.

## Problème

Le cache de pleine page est nettoyé après l’application de la mise à jour d’évaluation pour la règle de panier.

<u>Procédure à suivre </u> :

1. Activez le mode Développeur.
1. Ouvrez plusieurs pages de produits et de catégories et vérifiez (via les en-têtes) qu’elles sont chargées à partir du cache.
1. Appliquez une mise à jour d’évaluation pour la règle de panier.
1. Vérifiez si les pages de catégories et de produits sont toujours chargées à partir du cache.

<u>Résultats attendus</u> :

Le cache de pleine page n’est PAS nettoyé après l’application de la mise à jour d’évaluation pour la règle de panier.

<u>Résultats réels</u> :

Le cache de pleine page est nettoyé après l’application de la mise à jour d’évaluation pour la règle de panier.
