# AC-11389 : Les totaux des commandes varient en fonction des commandes auxquelles les produits sont ajoutés au panier

Le correctif AC-11389 corrige le problème en raison duquel les remises, les taxes et les totaux des commandes sont calculés de manière incorrecte dans certains scénarios d’arrondi. Ce correctif est disponible lorsque la version 1.1.83 de [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) est installée. L’ID du correctif est AC-11389. Notez que ce problème doit être résolu dans Adobe Commerce 2.4.9.

## Produits et versions concernés

**Le correctif est créé pour la version Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.8-p3

**Compatible avec les versions d’Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.6 - 2.4.8

>[!NOTE]
>
>Le correctif peut s’appliquer à d’autres versions avec de nouvelles versions de [!DNL Quality Patches Tool]. Pour vérifier si le correctif est compatible avec votre version d’Adobe Commerce, mettez à jour le package `magento/quality-patches` vers la dernière version et vérifiez la compatibilité sur la page [[!DNL Quality Patches Tool] : Rechercher des correctifs](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Utilisez l’ID du correctif comme mot-clé de recherche pour localiser le correctif.

## Problème

Les remises, les taxes et les totaux des commandes ne sont pas correctement calculés dans certains scénarios d&#39;arrondi.

<u>Conditions préalables</u> :

Créez des exemples de produits : (par exemple : *product1(hat)*, *product2(jacket)*)

<u>Procédure à suivre </u> :

1. Utilisez un magasin avec un taux de taxe de *22 %*, une remise de *10 %* sur le panier, un *chapeau* avec un prix spécial de *$733.61* et un *veste* avec un prix spécial de *$569.67*. 
1. Ajoutez *trois chapeaux* et *deux vestes* au panier, puis recommencez avec les produits ajoutés dans l&#39;ordre inverse.
1. Sélectionnez **[!UICONTROL Checkout]**, saisissez une adresse de livraison dans le pays où le taux de taxe s&#39;applique, appliquez le code remise et passez la commande. 

<u>Résultats attendus</u> :

Le montant total de la commande est de *$3667.52* pour chaque commande de produit.

<u>Résultats réels</u> :

Le total de la commande est de *$3667.51* lorsque les chapeaux sont ajoutés en premier et de *$3667.50* lorsque les vestes sont ajoutées en premier.
