# ACP2E-4639 : le type d’éléments de la liste de demandes est mal orthographié dans le schéma Adobe Commerce GraphQL

Le correctif ACP2E-4639 corrige le problème en raison duquel le type d&#39;éléments de la liste de demandes est mal orthographié dans le schéma GraphQL. Le nouveau champ de `requisition_list_items` renvoie le type de `RequisitionListItems` correctement orthographié, tandis que l’ancien champ de `items` et le type de `RequistionListItems` restent disponibles, mais sont obsolètes. Ce correctif est disponible lorsque la version 1.1.83 de [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) est installée. L’ID du correctif est ACP2E-4639. Notez que ce problème a été résolu dans Adobe Commerce B2B 1.5.3.

## Produits et versions concernés

**Le correctif est créé pour la version Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) B2B 1.5.2 - p1

**Compatible avec les versions d’Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) B2B >= 1.3.4 &lt; 1.5.3

>[!NOTE]
>
>Le correctif peut s’appliquer à d’autres versions avec de nouvelles versions de [!DNL Quality Patches Tool]. Pour vérifier si le correctif est compatible avec votre version d’Adobe Commerce, mettez à jour le package `magento/quality-patches` vers la dernière version et vérifiez la compatibilité sur la page [[!DNL Quality Patches Tool] : Rechercher des correctifs](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=fr). Utilisez l’ID du correctif comme mot-clé de recherche pour localiser le correctif.

## Problème

Le type d&#39;éléments de la liste de demandes est mal orthographié comme `RequistionListItems` dans le schéma GraphQL. L’ancien champ de `items` et le type de `RequistionListItems` restent disponibles, mais sont obsolètes.

<u>Conditions préalables</u> :

Adobe Commerce avec l’extension B2B

<u>Procédure à suivre </u> :

1. Envoyez la requête d’introspection GraphQL suivante :

   ```
   {
     __type(name: "RequisitionList") {
       fields(includeDeprecated: true) {
         name
         isDeprecated
         type {
           name
         }
       }
     }
   }
   ```

1. Dans la réponse, vérifiez le type renvoyé par le champ `items`.

<u>Résultats attendus</u> :

1. Le champ `requisition_list_items` renvoie le type de `RequisitionListItems` correctement orthographié.
1. Le champ `items` et le type de `RequistionListItems` restent disponibles et sont marqués comme obsolètes.

<u>Résultats réels</u> :

Le champ `items` renvoie le type de `RequistionListItems` mal orthographié, et aucun champ ne renvoie le type de `RequisitionListItems` correctement orthographié.
