# AC-18096 : les champs de date de GraphQL Sales renvoient un format localisé incorrect

Le correctif AC-18096 corrige le problème où les champs de date de Sales GraphQL renvoient des dates dans un format différent des versions précédentes en rétablissant le format de date d’un `/` séparé par des barres obliques à un `-` séparé par des tirets. Ce correctif est disponible lorsque la version 1.1.83 de [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) est installée. L’ID du correctif est AC-18096. Ce problème a été résolu dans Adobe Commerce 2.4.9.

## Produits et versions concernés

**Le correctif est créé pour la version Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.9

**Compatible avec les versions d’Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) >2.4.8 &lt;=2.4.9-p1

>[!NOTE]
>
>Le correctif peut s’appliquer à d’autres versions avec de nouvelles versions de [!DNL Quality Patches Tool]. Pour vérifier si le correctif est compatible avec votre version d’Adobe Commerce, mettez à jour le package `magento/quality-patches` vers la dernière version et vérifiez la compatibilité sur la page [[!DNL Quality Patches Tool] : Rechercher des correctifs](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=fr). Utilisez l’ID du correctif comme mot-clé de recherche pour localiser le correctif.

## Problème

Les champs de date de GraphQL Sales renvoient les valeurs de date et d’heure au format `(d/m/Y H:i:s)` avec des barres obliques au lieu du format avec des tirets `(Y-m-d H:i:s)` utilisé dans Adobe Commerce 2.4.8

<u>Conditions préalables</u> :

- **[!UICONTROL General]** > **[!UICONTROL Locale Options]** > **[!UICONTROL Timezone]** : *Europe/Paris*
- **[!UICONTROL General]** > **[!UICONTROL Locale Options]** > **[!UICONTROL Locale]** : *Français (France)*

<u>Procédure à suivre </u> :

1. Créer une commande.
1. Récupérez les détails de la date de commande à l’aide de GraphQL :

   ```graphql
   query getOrders {
       customer {
           orders {
               items {
                   orderDateOK: created_at
                   orderDateFAIL: order_date
               }
           }
       }
   }
   ```

<u>Résultats attendus</u> :

- Les champs renvoient des valeurs en `Y-m-d H:i:s`, correspondant à la sortie de la version 2.4.8.

<u>Résultats réels</u> :

- Les champs renvoient des valeurs en `d/m/Y H:i:s`, telles que `27/08/2026 14:12:55`, au lieu de `Y-m-d H:i:s`, telles que `2026-08-27 14:12:55`.
