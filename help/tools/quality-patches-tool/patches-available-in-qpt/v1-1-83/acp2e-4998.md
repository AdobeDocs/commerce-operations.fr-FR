# ACP2E-4998 : le SKU manquant empêche les mises à jour des prix de niveau en masse pour les produits valides

Le correctif ACP2E-4998 corrige le problème en raison duquel la requête de l’API REST `POST /V1/products/tier-prices` échouait entièrement lorsqu’un SKU n’existait pas dans la payload, empêchant la mise à jour des SKU valides. Ce correctif est disponible lorsque la version 1.1.83 de [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) est installée. L’ID du correctif est ACP2E-4998. Notez que ce problème doit être résolu dans Adobe Commerce 2.4.10.

## Produits et versions concernés

**Le correctif est créé pour la version Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.7 - p10

**Compatible avec les versions d’Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) >= 2.4.7 &lt; 2.4.8

>[!NOTE]
>
>Le correctif peut s’appliquer à d’autres versions avec de nouvelles versions de [!DNL Quality Patches Tool]. Pour vérifier si le correctif est compatible avec votre version d’Adobe Commerce, mettez à jour le package `magento/quality-patches` vers la dernière version et vérifiez la compatibilité sur la page [[!DNL Quality Patches Tool] : Rechercher des correctifs](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Utilisez l’ID du correctif comme mot-clé de recherche pour localiser le correctif.

## Problème

La requête d’API REST `POST /V1/products/tier-prices` a entièrement échoué lorsqu’un SKU n’existait pas dans la payload, empêchant la mise à jour de SKU valides.

<u>Procédure à suivre </u> :

1. Identifiez un SKU de produit existant, tel que `product_dynamic_1`, et un SKU qui n’existe pas dans le catalogue, tel que `product_dynamic_001`.
1. Envoyez une requête POST à `/rest/V1/products/tier-prices` contenant les deux SKU dans la même payload :

   ```json
   {
     "prices": [
       {
         "sku": "product_dynamic_1",
         "customer_group": "General",
         "quantity": 5,
         "price": 31.99,
         "price_type": "fixed",
         "website_id": 0
       },
       {
         "sku": "product_dynamic_001",
         "customer_group": "General",
         "quantity": 5,
         "price": 54.49,
         "price_type": "fixed",
         "website_id": 0
       }
     ]
   }
   ```

<u>Résultats attendus</u> :

1. Le prix du niveau est enregistré pour le SKU existant.
1. La réponse signale le SKU manquant comme une erreur au niveau de l’élément.

<u>Résultats réels</u> :

1. La requête échoue avec l&#39;erreur *Le produit avec le SKU « %1 » n&#39;existe pas.* par `product_dynamic_001`.
1. Aucun prix de niveau n’est enregistré pour le SKU existant.
