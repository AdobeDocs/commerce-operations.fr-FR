# AC-14940 : l’e-mail de réinitialisation de mot de passe n’est pas envoyé après la suppression de la vue du magasin d’un client

Le correctif AC-14940 corrige le problème en raison duquel le fait de cliquer sur [!UICONTROL Reset Password] pour un compte client dans l’administrateur n’envoie pas l’e-mail de réinitialisation de mot de passe dans certains cas liés au magasin . Ce correctif est disponible lorsque la version 1.1.83 de [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) est installée. L’ID du correctif est AC-14940. Notez que ce problème doit être résolu dans Adobe Commerce 2.4.9.

## Produits et versions concernés

**Le correctif est créé pour la version Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.7 - p10

**Compatible avec les versions d’Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) >= 2.4.4 &lt; 2.4.9

>[!NOTE]
>
>Le correctif peut s’appliquer à d’autres versions avec de nouvelles versions de [!DNL Quality Patches Tool]. Pour vérifier si le correctif est compatible avec votre version d’Adobe Commerce, mettez à jour le package `magento/quality-patches` vers la dernière version et vérifiez la compatibilité sur la page [[!DNL Quality Patches Tool] : Rechercher des correctifs](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=fr). Utilisez l’ID du correctif comme mot-clé de recherche pour localiser le correctif.

## Problème

Dans certains cas liés au magasin, cliquer sur [!UICONTROL Reset Password] pour créer un compte client dans l’Administration n’envoie pas l’e-mail de réinitialisation du mot de passe.

<u>Procédure à suivre </u> :

1. Dans Admin, accédez à **[!UICONTROL Stores]** > **[!UICONTROL Settings]** > **[!UICONTROL All Stores]** et créez une vue de magasin secondaire sous le **[!UICONTROL Main Website Store]** .
1. Accédez à la vue de magasin secondaire et créez un compte client.
1. Dans Admin, accédez à **[!UICONTROL Stores]** > **[!UICONTROL Settings]** > **[!UICONTROL All Stores]** et supprimez la vue de magasin secondaire.
1. Accédez à **[!UICONTROL Customers]** > **[!UICONTROL All Customers]**, recherchez le compte client, puis cliquez sur **[!UICONTROL Edit]**.
1. Cliquez sur **[!UICONTROL Reset Password]**.

<u>Résultats attendus</u> :

La demande de réinitialisation de mot de passe est terminée et le client reçoit un e-mail de réinitialisation de mot de passe.

<u>Résultats réels</u> :

Une page d’erreur affiche le message *Une erreur s’est produite lors de l’exécution de l’application. Voir le journal des exceptions pour plus de détails.*, et l’e-mail de réinitialisation du mot de passe n’est pas envoyé.
