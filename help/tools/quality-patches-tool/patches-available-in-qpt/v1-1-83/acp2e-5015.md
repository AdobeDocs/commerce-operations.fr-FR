# ACP2E-5015 : l’enregistrement de catalogue partagé supprime les affectations de produit et le prix après une erreur de lecture de session

Le correctif ACP2E-5015 corrige le problème en raison duquel l’enregistrement d’un catalogue partagé dans l’administration peut involontairement supprimer les produits affectés et le prix lorsque les données de catalogue requises ne sont pas disponibles. Ce correctif est disponible lorsque la version 1.1.83 de [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) est installée. L’ID du correctif est ACP2E-5015. Notez que ce problème doit être résolu dans la version 1.5.4 d’Adobe Commerce B2B.

## Produits et versions concernés

**Le correctif est créé pour la version Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) B2B 1.5.2-p4

**Compatible avec les versions d’Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) B2B >=1.3.4 &lt;1.5.4

>[!NOTE]
>
>Le correctif peut s’appliquer à d’autres versions avec de nouvelles versions de [!DNL Quality Patches Tool]. Pour vérifier si le correctif est compatible avec votre version d’Adobe Commerce, mettez à jour le package `magento/quality-patches` vers la dernière version et vérifiez la compatibilité sur la page [[!DNL Quality Patches Tool] : Rechercher des correctifs](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=fr). Utilisez l’ID du correctif comme mot-clé de recherche pour localiser le correctif.

## Problème

L’enregistrement d’un catalogue partagé dans l’administration peut involontairement supprimer les produits affectés et le prix lorsque les données de catalogue requises ne sont pas disponibles.

<u>Conditions préalables</u> :

Adobe Commerce avec l’extension B2B **[!UICONTROL Enable Company]** et **[!UICONTROL Enable Shared Catalog]** sont définis sur *Oui*.

<u>Procédure à suivre </u> :

1. Dans la barre latérale d’administration, accédez à **[!UICONTROL Stores]** > **[!UICONTROL Settings]** > **[!UICONTROL Configuration]** > **[!UICONTROL General]** > **[!UICONTROL B2B Features]**.
1. Définissez **[!UICONTROL Enable Company]** sur *Oui*.
1. Définissez **[!UICONTROL Enable Shared Catalog]** sur *Oui*.
1. Accédez à **[!UICONTROL Catalog]** > **[!UICONTROL Shared Catalogs]**, cliquez sur **[!UICONTROL Add Shared Catalog]**, saisissez un nom, puis cliquez sur **[!UICONTROL Save]**.
1. Dans la colonne **[!UICONTROL Actions]** du nouveau catalogue partagé, sélectionnez **[!UICONTROL Set Pricing and Structure]**, cliquez sur **[!UICONTROL Configure]** si elle est affichée, sélectionnez tous les produits disponibles, puis cliquez sur **[!UICONTROL Next]**.
1. Cliquez sur **[!UICONTROL Generate Catalog]**, puis sur **[!UICONTROL Save]**.
1. Rouvrez **[!UICONTROL Set Pricing and Structure]** pour le catalogue partagé et vérifiez que les produits sont affectés dans l’arborescence des catégories.
1. Lorsque l’assistant de catalogue partagé est ouvert, le stockage de la session active renvoie une erreur de lecture, telle qu’une erreur de lecture des données de la session [!DNL Valkey].
1. Cliquez sur **[!UICONTROL Save]**.
1. Rouvrez **[!UICONTROL Set Pricing and Structure]** et examinez l’arborescence des catégories et la structure de tarification.

<u>Résultats attendus</u> :

- L’enregistrement du catalogue partagé est bloqué lorsque les données de session requises ne peuvent pas être lues.
- Les affectations de produits et les prix existants restent inchangés.

<u>Résultats réels</u> :

- L’enregistrement du catalogue partagé se termine malgré l’erreur de lecture des données de session.
- Les données de session manquantes sont traitées comme vides, supprimant tous les produits affectés et réinitialisant la structure de tarification du catalogue partagé.
