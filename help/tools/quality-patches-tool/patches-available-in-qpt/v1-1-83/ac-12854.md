# AC-12854 : la réorganisation de l’administrateur utilise le numéro de commande d’origine avec un suffixe `-1`

Le correctif AC-12854 corrige le problème en raison duquel la réorganisation d’une commande dans l’administration crée un nouveau numéro de commande avec un suffixe `-1` au lieu d’attribuer le numéro de commande séquentiel suivant. Ce correctif est disponible lorsque la version 1.1.83 de [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) est installée. L’ID du correctif est AC-12854. Notez que ce problème doit être résolu dans Adobe Commerce 2.4.9.

## Produits et versions concernés

**Le correctif est créé pour la version Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.7-p9

**Compatible avec les versions d’Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) >=2.4.7 &lt; 2.4.9

>[!NOTE]
>
>Le correctif peut s’appliquer à d’autres versions avec de nouvelles versions de [!DNL Quality Patches Tool]. Pour vérifier si le correctif est compatible avec votre version d’Adobe Commerce, mettez à jour le package `magento/quality-patches` vers la dernière version et vérifiez la compatibilité sur la page [[!DNL Quality Patches Tool] : Rechercher des correctifs](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Utilisez l’ID du correctif comme mot-clé de recherche pour localiser le correctif.

## Problème

La réorganisation d’une commande dans l’administrateur crée un nouveau numéro de commande avec un suffixe `-1` au lieu d’attribuer le numéro de commande séquentiel suivant.

<u>Procédure à suivre </u> :

1. Utilisez une commande client existante avec des articles réorganisables.
1. Dans la barre latérale d’administration, accédez à **[!UICONTROL Sales]** > **[!UICONTROL Orders]**.
1. Ouvrez la commande en mode **Affichage** et cliquez sur **[!UICONTROL Reorder]** dans la barre de boutons supérieure.
1. Sur la page **[!UICONTROL Create New Order]**, renseignez les champs requis et cliquez sur **[!UICONTROL Submit Order]**.

<u>Résultats attendus</u> :

Une nouvelle commande **En attente** est créée avec le numéro de commande séquentiel unique suivant.

<u>Résultats réels</u> :

La nouvelle commande obtient le numéro de commande d’origine avec un suffixe `-1` au lieu du numéro de commande suivant.
