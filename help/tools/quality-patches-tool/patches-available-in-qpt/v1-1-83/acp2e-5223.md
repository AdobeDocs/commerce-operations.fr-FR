# ACP2E-5223 : l’index des autorisations de catalogue inclut les sites web exclus des groupes de clients

Le correctif ACP2E-5223 corrige le problème en raison duquel l’index **[!UICONTROL Category Permissions]** inclut les sites web qui sont exclus d’un groupe de clients. Ce correctif est disponible lorsque la version 1.1.83 de [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) est installée. L’ID du correctif est ACP2E-5223. Notez que ce problème doit être résolu dans Adobe Commerce 2.4.10.

## Produits et versions concernés

**Le correctif est créé pour la version Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.8-p5

**Compatible avec les versions d’Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) >=2.4.8 &lt;2.4.9

>[!NOTE]
>
>Le correctif peut s’appliquer à d’autres versions avec de nouvelles versions de [!DNL Quality Patches Tool]. Pour vérifier si le correctif est compatible avec votre version d’Adobe Commerce, mettez à jour le package `magento/quality-patches` vers la dernière version et vérifiez la compatibilité sur la page [[!DNL Quality Patches Tool] : Rechercher des correctifs](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=fr). Utilisez l’ID du correctif comme mot-clé de recherche pour localiser le correctif.

## Problème

L’index **[!UICONTROL Category Permissions]** inclut les sites web qui sont exclus d’un groupe de clients.


**Aucune**

<u>Procédure à suivre </u> :

1. Créer plusieurs sites web : site web principal, site web2.
1. Créer des catégories.
1. Créer des produits.
1. Créez des groupes de clients avec des exclusions via le **[!UICONTROL Admin]** : accédez à **[!UICONTROL Customers]** > **[!UICONTROL Customer Groups]**.
   - Exclure le site Web2
   - Exclure le site web principal
1. Accédez à **[!UICONTROL Catalog]** > **[!UICONTROL Categories]**, puis sélectionnez une catégorie.
1. Faites défiler l’écran jusqu’à la section **[!UICONTROL Category Permissions]** .
1. Cliquez sur **[!UICONTROL Add Permission]**, puis définissez les éléments suivants :
   - **[!UICONTROL Website]** : *Tous les sites web*
   - **[!UICONTROL Customer Group]** : *Tous les groupes de clients*
   - **[!UICONTROL Browsing Category]** : *Autoriser*
   - **[!UICONTROL Display Product Prices]** : *Autoriser*
   - **[!UICONTROL Add to Cart]** : *Autoriser*
1. Enregistrez la catégorie.

<u>Résultats attendus</u> :

- L’index contient uniquement des combinaisons site web/groupe valides et autorisées.
- Les combinaisons exclues sont filtrées pendant l’indexation.

<u>Résultats réels</u> :

- L’index contient des lignes pour les combinaisons site web/groupe exclues.
