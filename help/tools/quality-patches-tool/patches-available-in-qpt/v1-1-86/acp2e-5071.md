# ACP2E-5071 : le message d’indisponibilité des stocks n’est pas toujours affiché sur la page des produits lorsque le panier de l’acheteur contient la quantité disponible complète

Le correctif ACP2E-5071 corrige le problème en raison duquel le message d’indisponibilité des stocks n’est pas toujours affiché sur la page des produits lorsque le panier de l’acheteur contient déjà la quantité disponible complète. Ce correctif est disponible lorsque la version [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.86 est installée. L’ID du correctif est ACP2E-5071. Notez que ce problème doit être résolu dans Adobe Commerce 2.4.10.

## Produits et versions concernés

**Le correctif est créé pour la version Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.8

**Compatible avec les versions d’Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.7 - 2.4.9

>[!NOTE]
>
>Le correctif peut s’appliquer à d’autres versions avec de nouvelles versions de [!DNL Quality Patches Tool]. Pour vérifier si le correctif est compatible avec votre version d’Adobe Commerce, mettez à jour le package `magento/quality-patches` vers la dernière version et vérifiez la compatibilité sur la page [[!DNL Quality Patches Tool] : Rechercher des correctifs](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=fr). Utilisez l’ID du correctif comme mot-clé de recherche pour localiser le correctif.

## Problème

Le message d’indisponibilité du stock ne s’affiche pas toujours sur la page produit lorsque le panier de l’acheteur contient déjà la quantité disponible complète.

<u>Conditions Préalables</u> :

Cache de pleine page activé (intégré, vernis ou Fastly).

<u>Procédure à suivre</u> :

1. Dans le panneau d’administration, accédez au **Catalogue** > **Produits** et créez un produit simple (**Ajouter un produit** > **Produit simple**) ou ouvrez un produit existant.
1. Définissez Quantité sur 2 et Statut du stock sur En stock, puis cliquez sur Enregistrer. S&#39;il existe plusieurs origines de stock, définissez Qté sur 2 pour l&#39;origine affectée dans la section Origines.
1. En tant qu’invité dans une fenêtre de navigateur privé, ouvrez la page produit sur le Storefront et rechargez-la une fois afin qu’elle soit diffusée à partir du cache de page complet.
1. Définissez Qté sur 2 et cliquez sur **[!UICONTROL Add to Cart]**.
1. Pour faciliter la reproduction du problème, ouvrez les outils de développement du navigateur et, dans le panneau Performances, définissez Limitation CPU sur 6 fois le ralentissement.
1. Définissez Qté sur 1 et cliquez sur **[!UICONTROL Add to Cart]**. La page se recharge et affiche un message d’erreur de stock, par exemple : Pas assez d’articles à vendre.
1. Cliquez de nouveau sur **[!UICONTROL Add to Cart]** plusieurs fois, jusqu’à quelques dizaines, et laissez la page se recharger après chaque clic.

<u>Résultats attendus</u> :

1. Chaque tentative d’ajout au panier échouée affiche le message d’erreur du stock.

<u>Résultats réels</u> :

1. Après quelques tentatives, la page se recharge sans afficher le message d’erreur.
