# ACP2E-4191 : les requêtes d’API REST entrent en boucle infinie lorsque le cache des types et attributs EAV est désactivé

Le correctif ACP2E-4191 corrige le problème où certaines requêtes d’API REST entrent en boucle infinie lorsque le cache des types et attributs EAV est désactivé. Ce correctif est disponible lorsque la version [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.86 est installée. L’ID du correctif est ACP2E-4191. Ce problème a été résolu dans Adobe Commerce 2.4.9.

## Produits et versions concernés

**Le correctif est créé pour la version Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.7-p9, 2.4.8-p2

**Compatible avec les versions d’Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.5 - 2.4.8-p5

>[!NOTE]
>
>Le correctif peut s’appliquer à d’autres versions avec de nouvelles versions de [!DNL Quality Patches Tool]. Pour vérifier si le correctif est compatible avec votre version d’Adobe Commerce, mettez à jour le package `magento/quality-patches` vers la dernière version et vérifiez la compatibilité sur la page [[!DNL Quality Patches Tool] : Rechercher des correctifs](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Utilisez l’ID du correctif comme mot-clé de recherche pour localiser le correctif.

## Problème

Certaines requêtes de l’API REST entrent dans une boucle infinie lorsque le cache des types et attributs EAV est désactivé.

<u>Conditions Préalables</u> :

Extension Adobe Commerce [!DNL B2B].

<u>Procédure à suivre</u> :

1. Créez un compte client et connectez-vous au Storefront.
1. Ajoutez un produit au panier et ouvrez la page de passage en caisse.
1. Dans les outils de développement du navigateur, ouvrez l’onglet Réseau et examinez les requêtes REST, telles que `rest/default/V1/carts/mine/estimate-shipping-methods`.
1. Désactivez le cache des types et attributs EAV :

   ```
   bin/magento cache:disable eav
   ```

1. Actualisez la page de passage en caisse et examinez les mêmes requêtes REST.

<u>Résultats attendus</u> :

1. Les requêtes REST d’extraction se terminent sans entrer dans une boucle infinie.

<u>Résultats réels</u> :

1. Les requêtes REST échouent avec une erreur HTTP 500 car la boucle infinie atteint la taille de la pile des appels PHP ou la limite de la mémoire.
