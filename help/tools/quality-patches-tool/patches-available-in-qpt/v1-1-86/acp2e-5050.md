# ACP2E-5050 : L&#39;affichage ou l&#39;enregistrement de la RMA dans Admin n&#39;affiche pas le numéro de RMA dans le rapport Journaux d&#39;actions

Le correctif ACP2E-5050 corrige le problème où l&#39;affichage ou l&#39;enregistrement d&#39;une autorisation de retour dans l&#39;Administration n&#39;affichait pas le numéro d&#39;autorisation de retour dans le rapport **[!UICONTROL Action Logs]**. Ce correctif est disponible lorsque la version [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.86 est installée. L’ID du correctif est ACP2E-5050. Notez que ce problème doit être résolu dans Adobe Commerce 2.4.10.

## Produits et versions concernés

**Le correctif est créé pour la version Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.8-p5

**Compatible avec les versions d’Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.6 - 2.4.9

>[!NOTE]
>
>Le correctif peut s’appliquer à d’autres versions avec de nouvelles versions de [!DNL Quality Patches Tool]. Pour vérifier si le correctif est compatible avec votre version d’Adobe Commerce, mettez à jour le package `magento/quality-patches` vers la dernière version et vérifiez la compatibilité sur la page [[!DNL Quality Patches Tool] : Rechercher des correctifs](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Utilisez l’ID du correctif comme mot-clé de recherche pour localiser le correctif.

## Problème

L&#39;affichage ou l&#39;enregistrement d&#39;une autorisation de retour client dans Admin n&#39;affiche pas le numéro d&#39;autorisation de retour client dans le rapport **[!UICONTROL Action Logs]**.

<u>Procédure à suivre</u> :

1. Commandez un produit simple sur la vitrine ou dans le panneau d’administration.
1. Dans le panneau d’administration, accédez à **[!UICONTROL Sales]** > **[!UICONTROL Orders]**, ouvrez la commande, cliquez sur **[!UICONTROL Ship]**, puis sur **[!UICONTROL Submit Shipment]**.
1. Sur la page de commande, cliquez sur **[!UICONTROL Create Returns]**. Dans l’onglet **[!UICONTROL Return Items]**, cliquez sur **[!UICONTROL Add Products]**, sélectionnez le produit, puis cliquez sur **[!UICONTROL Add Selected Product(s) to returns]**.
1. Saisissez la quantité **[!UICONTROL Requested]**, sélectionnez un(e) **[!UICONTROL Return Reason]**, **[!UICONTROL Item Condition]** et **[!UICONTROL Resolution]**, puis cliquez sur **[!UICONTROL Submit Returns]**.
1. Accédez à **[!UICONTROL Sales]** > **[!UICONTROL Returns]** et ouvrez le nouveau retour.
1. Accédez à **[!UICONTROL System]** > **[!UICONTROL Action Logs]** > **[!UICONTROL Report]**, définissez le filtre **[!UICONTROL Action Group]** sur *Renvoie*, cliquez sur **[!UICONTROL Search]** et vérifiez la colonne **[!UICONTROL Details]**.

<u>Résultats attendus</u> :

L&#39;entrée *Enregistrer* consignée lors de l&#39;envoi du retour et l&#39;entrée *Afficher* consignée lors de son ouverture affichent son numéro RMA dans la colonne **[!UICONTROL Details]**.

<u>Résultats réels</u> :

Ces entrées affichent uniquement un tiret dans la colonne **[!UICONTROL Details]**, sans le numéro RMA.
