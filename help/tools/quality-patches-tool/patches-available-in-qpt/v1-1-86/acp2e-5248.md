# ACP2E-5248 : les utilisateurs administrateurs sans autorisation [!UICONTROL Edit Product Status] voient l’erreur d’obsolescence sur la page [!UICONTROL Add Product] de PHP 8.5.

Le correctif ACP2E-5248 corrige le problème où les utilisateurs administrateurs sans l’autorisation [!UICONTROL Edit Product Status] voient l’erreur d’obsolescence *null comme décalage de tableau* lors de l’ouverture de la page [!UICONTROL Add Product] sur PHP 8.5. Ce correctif est disponible lorsque la version [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.86 est installée. L’ID du correctif est ACP2E-5248. Notez que ce problème doit être résolu dans Adobe Commerce 2.4.10.

## Produits et versions concernés

**Le correctif est créé pour la version Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.9

**Compatible avec les versions d’Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.5 - 2.4.9

>[!NOTE]
>
>Le correctif peut s’appliquer à d’autres versions avec de nouvelles versions de [!DNL Quality Patches Tool]. Pour vérifier si le correctif est compatible avec votre version d’Adobe Commerce, mettez à jour le package `magento/quality-patches` vers la dernière version et vérifiez la compatibilité sur la page [[!DNL Quality Patches Tool] : Rechercher des correctifs](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Utilisez l’ID du correctif comme mot-clé de recherche pour localiser le correctif.

## Problème

Les utilisateurs administrateurs sans l’autorisation [!UICONTROL Edit Product Status] voient l’erreur d’obsolescence *null comme décalage de tableau* lors de l’ouverture de la page [!UICONTROL Add Product] sur PHP 8.5.

<u>Conditions Préalables</u> :

Adobe Commerce exécuté sur PHP 8.5

<u>Procédure à suivre</u> :

1. Dans le panneau d’administration, accédez à **[!UICONTROL System]** > **[!UICONTROL Permissions]** > **[!UICONTROL User Roles]**, puis cliquez sur **[!UICONTROL Add New Role]**.
1. Dans l’onglet **[!UICONTROL Role Info]**, saisissez un **[!UICONTROL Role Name]** et votre mot de passe dans **[!UICONTROL Your Password]**.
1. Dans l’onglet **[!UICONTROL Role Resources]**, définissez **[!UICONTROL Resource Access]** sur *Personnalisé*, sélectionnez **[!UICONTROL Catalog]** > **[!UICONTROL Inventory]** > **[!UICONTROL Products]**, effacez **[!UICONTROL Edit Product Status]** sous-jacent, puis cliquez sur **[!UICONTROL Save Role]**.
1. Accédez à **[!UICONTROL System]** > **[!UICONTROL Permissions]** > **[!UICONTROL All Users]**, puis cliquez sur **[!UICONTROL Add New User]**.
1. Renseignez les champs obligatoires dans l’onglet **[!UICONTROL User Info]**, sélectionnez le nouveau rôle dans l’onglet **[!UICONTROL User Role]**, puis cliquez sur **[!UICONTROL Save User]**.
1. Déconnectez-vous et connectez-vous au panneau d’administration en tant que nouvel utilisateur.
1. Accédez à **[!UICONTROL Catalog]** > **[!UICONTROL Products]**, puis cliquez sur **[!UICONTROL Add Product]**.

<u>Résultats attendus</u> :

La page [!UICONTROL New Product] s’ouvre avec le formulaire de produit.

<u>Résultats réels</u> :

Au lieu du formulaire de produit, la page [!UICONTROL New Product] affiche une erreur de fonctionnalité obsolète : *L’utilisation de la valeur null comme décalage de tableau est obsolète, utilisez une chaîne vide à la place.*
