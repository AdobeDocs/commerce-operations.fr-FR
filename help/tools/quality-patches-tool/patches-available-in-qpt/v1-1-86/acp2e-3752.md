# ACP2E-3752 : l’importation de produit renvoie une erreur de clé de tableau indéfinie lorsque de nombreuses opérations d’importation s’exécutent

Le correctif ACP2E-3752 corrige le problème en raison duquel le traitement de l&#39;importation de produits renvoie l&#39;erreur *Avertissement : clé de tableau non définie « apply_to »* lorsque de nombreuses opérations d&#39;importation de produits sont créées. Ce correctif est disponible lorsque la version [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.86 est installée. L’ID du correctif est ACP2E-3752. Ce problème a été résolu dans Adobe Commerce 2.4.9.

## Produits et versions concernés

**Le correctif est créé pour la version Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.7, 2.4.8-p5

**Compatible avec les versions d’Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.7 - 2.4.8-p5

>[!NOTE]
>
>Le correctif peut s’appliquer à d’autres versions avec de nouvelles versions de [!DNL Quality Patches Tool]. Pour vérifier si le correctif est compatible avec votre version d’Adobe Commerce, mettez à jour le package `magento/quality-patches` vers la dernière version et vérifiez la compatibilité sur la page [[!DNL Quality Patches Tool] : Rechercher des correctifs](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Utilisez l’ID du correctif comme mot-clé de recherche pour localiser le correctif.

## Problème

Le traitement de l&#39;import de produit renvoie l&#39;erreur *Avertissement : clé de tableau non définie « apply_to »* lorsque de nombreuses opérations d&#39;import de produit sont créées.

<u>Procédure à suivre</u> :

1. Dans l’administration, accédez à **[!UICONTROL Stores]** > **[!UICONTROL Attributes]** > **[!UICONTROL Attribute Set]**, ouvrez le jeu d’attributs *Default*, faites glisser l’attribut `color` de **[!UICONTROL Unassigned Attributes]** dans un groupe, puis cliquez sur **[!UICONTROL Save]**.
1. Accédez à **[!UICONTROL Stores]** > **[!UICONTROL Attributes]** > **[!UICONTROL Product]**, ouvrez l’attribut `color`, ajoutez quelques options sous **[!UICONTROL Manage Options (Values of Your Attribute)]** et cliquez sur **[!UICONTROL Save Attribute]**.
1. Exécutez un processus personnalisé qui crée une instance de modèle d&#39;import de produit plusieurs fois dans le même processus PHP. Par exemple, utilisez la commande de console d’un module personnalisé qui crée l’instance 10 000 fois dans une boucle.

<u>Résultats attendus</u> :

Le processus se termine sans erreur.

<u>Résultats réels</u> :

Le processus échoue avec l&#39;erreur *Avertissement : clé de tableau non définie « apply_to »*, selon le moment où le nettoyage de la mémoire PHP s&#39;exécute.
