# ACP2E-5046 : actualisation de la page lors de la création d’une commande dans Admin et ajout multiple du même SKU

Le correctif ACP2E-5046 corrige le problème en raison duquel l’actualisation de la page lors de la création d’une commande dans l’administrateur ajoute le même SKU plusieurs fois. Ce correctif est disponible lorsque la version [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.86 est installée. L’ID du correctif est ACP2E-5046. Notez que ce problème doit être résolu dans Adobe Commerce 2.4.10.

## Produits et versions concernés

**Le correctif est créé pour la version Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.8-p4

**Compatible avec les versions d’Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.5 - 2.4.9

>[!NOTE]
>
>Le correctif peut s’appliquer à d’autres versions avec de nouvelles versions de [!DNL Quality Patches Tool]. Pour vérifier si le correctif est compatible avec votre version d’Adobe Commerce, mettez à jour le package `magento/quality-patches` vers la dernière version et vérifiez la compatibilité sur la page [[!DNL Quality Patches Tool] : Rechercher des correctifs](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Utilisez l’ID du correctif comme mot-clé de recherche pour localiser le correctif.

## Problème

Actualiser la page lors de la création d’une commande dans Admin ajoute le même SKU plusieurs fois.

<u>Procédure à suivre</u> :

1. Dans le panneau d’administration, accédez à **[!UICONTROL Sales]** > **[!UICONTROL Orders]**.
1. Cliquez sur **[!UICONTROL Create New Order]**, puis sélectionnez un client.
1. Cliquez sur **[!UICONTROL Add Products By SKU]**.
1. Saisissez le SKU d&#39;un produit existant et une quantité, puis cliquez sur **[!UICONTROL Add to Order]**.
1. Actualisez la page, confirmez le nouvel envoi du formulaire si le navigateur vous le demande, puis vérifiez la quantité de SKU ajoutée.

<u>Résultats attendus</u> :

Le SKU reste à la quantité saisie une fois la page actualisée.

<u>Résultats réels</u> :

Chaque actualisation de page ajoute à nouveau le même SKU, ce qui augmente sa quantité.
