# ACP2E-5425 : les clients reçoivent des e-mails de confirmation de commande en double pour la même commande

Le correctif ACP2E-5425 corrige le problème en raison duquel les clients reçoivent des e-mails de confirmation de commande en double pour la même commande. Ce correctif est disponible lorsque la version [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.86 est installée. L’ID du correctif est ACP2E-5425. Notez que ce problème doit être résolu dans Adobe Commerce 2.4.10.

## Produits et versions concernés

**Le correctif est créé pour la version Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.7-p10

**Compatible avec les versions d’Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.5 - 2.4.7-p10

>[!NOTE]
>
>Le correctif peut s’appliquer à d’autres versions avec de nouvelles versions de [!DNL Quality Patches Tool]. Pour vérifier si le correctif est compatible avec votre version d’Adobe Commerce, mettez à jour le package `magento/quality-patches` vers la dernière version et vérifiez la compatibilité sur la page [[!DNL Quality Patches Tool] : Rechercher des correctifs](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=fr). Utilisez l’ID du correctif comme mot-clé de recherche pour localiser le correctif.

## Problème

Les clients reçoivent des e-mails de confirmation de commande en double pour la même commande.

<u>Procédure à suivre</u> :

1. Dans le panneau d’administration, accédez à **[!UICONTROL Stores]** > **[!UICONTROL Settings]** > **[!UICONTROL Configuration]** > **[!UICONTROL Sales]** > **[!UICONTROL Sales Emails]**, développez **[!UICONTROL General Settings]**, effacez **[!UICONTROL Use system value]**, définissez **[!UICONTROL Asynchronous sending]** sur *Activer*, puis cliquez sur **[!UICONTROL Save Config]**.
1. Passez une nouvelle commande sur le Storefront en utilisant une adresse e-mail client valide et effectuez le passage en caisse.
1. Faites en sorte que deux processus exécutent la tâche cron `sales_send_order_emails` en même temps, de sorte que les deux récupèrent l’e-mail de confirmation de commande en file d’attente.
1. Vérifiez les messages de confirmation de commande dans la boîte de réception du client.

<u>Résultats attendus</u> :

Un seul e-mail de confirmation de commande est envoyé pour la commande.

<u>Résultats réels</u> :

Deux e-mails de confirmation de commande identiques sont envoyés au client pour la même commande.

## Étapes supplémentaires requises après l’installation du correctif

Après avoir appliqué le correctif, exécutez `setup:upgrade` pour mettre à jour les colonnes `email_sent`.
