# ACP2E-4665 : les produits enfants de produits configurables avec des vidéos dans les galeries de produits n’apparaissent pas lorsqu’ils sont demandés via l’API REST

Le correctif ACP2E-4665 corrige le problème où les produits enfants d’un produit configurable ne sont pas renvoyés par l’API REST lorsqu’une vidéo est incluse dans la galerie de produits. Ce correctif est disponible lorsque la version 1.1.78 de [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) est installée. L’ID du correctif est ACP2E-4665. Notez que ce problème doit être résolu dans Adobe Commerce 2.4.9.

## Produits et versions concernés

**Le correctif est créé pour la version Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.8-p3

**Compatible avec les versions d’Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.8 - 2.4.8-p4

>[!NOTE]
>
>Le correctif peut s’appliquer à d’autres versions avec de nouvelles versions de [!DNL Quality Patches Tool]. Pour vérifier si le correctif est compatible avec votre version d’Adobe Commerce, mettez à jour le package `magento/quality-patches` vers la dernière version et vérifiez la compatibilité sur la page [[!DNL Quality Patches Tool] : Rechercher des correctifs](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=fr). Utilisez l’ID du correctif comme mot-clé de recherche pour localiser le correctif.

## Problème

L’API REST ne renvoie pas les produits enfants d’un produit configurable lorsqu’une vidéo est présente dans la galerie de produits.

<u>Procédure à suivre </u> :

1. Ajouter une vidéo au produit enfant d’un produit configurable.
1. Envoyez une requête au point d’entrée de l’API REST suivant :
   `rest/v1/configurable-products/<PARENT_CONFIGURABLE_PRODUCT_SKU>/children`.

<u>Résultats attendus</u> :

L’API REST renvoie des informations sur le produit.

<u>Résultats réels</u> :

L’API REST renvoie l’erreur suivante :

```
Error: Call to a member function getVideoProvider() on null in vendor/magento/module-product-video/Model/Product/Attribute/Media/ExternalVideoEntryConverter.php:87" exception.
```
