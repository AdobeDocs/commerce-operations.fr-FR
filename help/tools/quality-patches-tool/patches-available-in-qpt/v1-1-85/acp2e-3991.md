# ACP2E-3991 : l&#39;adresse IP du client n&#39;est pas déterminée correctement

Le correctif ACP2E-3991 corrige le problème en raison duquel l’adresse IP du client n’est pas déterminée correctement et est enregistrée sous la forme `127.0.0.1` dans le champ `remote_ip` de la table `sales_order`. Ce correctif est disponible lorsque la version [[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.85 est installée. L’ID du correctif est ACP2E-3991. Notez que ce problème est résolu dans Adobe Commerce 2.4.9.

## Produits et versions concernés

**Le correctif est créé pour la version Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.7-p6, 2.4.8-p5

**Compatible avec les versions d’Adobe Commerce :**

* Adobe Commerce (toutes les méthodes de déploiement) 2.4.7 - 2.4.8-p5

>[!NOTE]
>
>Le correctif peut s’appliquer à d’autres versions avec de nouvelles versions de [!DNL Quality Patches Tool]. Pour vérifier si le correctif est compatible avec votre version d’Adobe Commerce, mettez à jour le package `magento/quality-patches` vers la dernière version et vérifiez la compatibilité sur la page [[!DNL Quality Patches Tool] : Rechercher des correctifs](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html). Utilisez l’ID du correctif comme mot-clé de recherche pour localiser le correctif.

## Problème

Problème en raison duquel l’adresse IP du client n’est pas déterminée correctement et est enregistrée en tant que `127.0.0.1` dans le champ `remote_ip` de la table `sales_order`.

<u>Procédure à suivre</u> :

1. Configurez le serveur d’applications GraphQL dans une instance Commerce Cloud.
1. Passer une commande via GraphQL.
1. Vérifiez le champ `remote_ip` dans la table `sales_order` pour l’ordre que vous avez créé.
1. Vérifiez le journal d’accès.

<u>Résultats attendus</u> :

L’adresse IP correcte est consignée, même lorsque la requête est acheminée via GraphQL.

<u>Résultats réels</u> :

Le champ `remote_ip` est enregistré en tant que `127.0.0.1` au lieu de l’adresse IP réelle du client.
